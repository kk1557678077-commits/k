# 小奥迪A7的赛车梦 · 儿童画风格动画（30秒）

成片：[`audi-a7-racing-story.mp4`](audi-a7-racing-story.mp4)（1280×720，24fps，30秒，带配乐和音效）

画面全部用代码"画"出来：蜡笔质感的填色、每秒重画 8 次的抖动线条（手绘动画的感觉）、歪歪扭扭的彩色手写字幕；配乐（玩具钢琴小曲）和音效（引擎、倒数、喇叭、泥巴、欢呼、烟花）也都是程序合成的。

| --- | --- | --- |
| 0–4.5 秒 | 红色小奥迪 A7 开进画面，按喇叭"嘀嘀！" | 小奥迪A7的赛车梦 / 一场关于勇气和友谊的比赛 |

| 15–21 秒 | 小黄车陷进泥坑哭了，A7 停下来，打开 quattro 四驱把它推出来 | 哎呀！小黄车陷进泥坑里了！ / A7打开quattro四驱，一起用力推！ / 谢谢你，A7！你是我的好朋友！ |

| 26–30 秒 | 夜空烟花，领奖台和金奖杯，三位好朋友一起庆祝 | 友谊第一，比赛第二！ · 完 |

## 重新生成

需要 Python 3、NumPy、Pillow、ffmpeg，以及文泉驿正黑字体（`fonts-wqy-zenhei`）。

```bash
python3 kids-video/make_video.py                                  # 渲染整片（约 1 分钟）
python3 kids-video/make_video.py --still 12 18.5 --outdir /tmp    # 只预览某几秒的画面
python3 kids-video/soundtrack.py /tmp/soundtrack.wav              # 只生成配乐
```

- `make_video.py`：画面（场景、汽车、人物、字幕）和最终合成
- `soundtrack.py`：配乐与音效，时间点和画面一一对应
